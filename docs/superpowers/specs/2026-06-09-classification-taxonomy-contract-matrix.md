Scope: Phase 0 documentation only for `docs/superpowers/plans/2026-06-09-classification-taxonomy-unification.md`.

## Runtime Drop Source Kind Vs NPC Loot Taxonomy Audit Status

Runtime `npc_loot_entries.drop_source_kind` labels are for displayed loot rows:

| Runtime Kind | Runtime Meaning | Intended Runtime Label Owner |
| --- | --- | --- |
| `npc_drop` | Ordinary NPC drop row. | Backend Phase 1 `dropSourceKindLabel`; UI displays the backend label. |
| `direct_boss` | Boss body/direct drop row. | Backend Phase 1 `dropSourceKindLabel`; current local labels must be replaced/aligned. |
| `treasure_bag` | Expert/master treasure bag loot row. | Backend Phase 1 `dropSourceKindLabel`; current local labels must be replaced/aligned. |
| `unknown` | Planned response-level label behavior for null or unrecognized runtime kinds. | Backend Phase 1; must not be written back to DB by UI. |

NPC loot taxonomy audit statuses are audit/materialization decisions from `docs/contracts/npc-loot-source-taxonomy-contract.md`, not runtime UI drop kinds:

| Audit Status | Contract Role | UI Runtime Label Use |
| --- | --- | --- |
| `accepted` | Row may materialize into NPC loot relation flows. | Forbidden as a drop source kind label. |
| `generic_bucket` | Collective bucket, audit-only until reviewed. | Forbidden as a drop source kind label. |
| `contract_mismatch` | Resolved NPC violates reviewed contract. | Forbidden as a drop source kind label. |
| `non_npc_source_misclassified` | Source is not an NPC source. | Forbidden as a drop source kind label. |
| `true_ambiguous`, `blocked`, `needs_review` | Audit control states. | Forbidden as runtime labels. |

The audit taxonomy may appear in reports or read-only audit endpoints. It must not be renamed into `npc_drop`, `direct_boss`, `treasure_bag`, or public/admin loot labels.
