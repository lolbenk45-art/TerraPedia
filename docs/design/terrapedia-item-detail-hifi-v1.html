设计注记 · 物品详情页 v1

  1. 合成链升格为主线模块：原「制作此物品」只给一张摘要卡 + 跳转按钮，现在按 L3 基础材料 → L2 中间产物 → L1 核心部件 → 成品 分层平铺，制作站随层显示，猩红／腐化世界的二选一材料用显式分支表达。
  2. 新增采集清单：把树摊平成可勾选的备料表——这是玩家真正要带走的东西。当前按配方原始数量列出，跨层数量换算（如叶绿锭 ×24 需要多少叶绿矿）留作后续。
  3. 空模块不再占整卡：来源／状态效果／装备属性／图片压成 4 行事实条，每行说清「是什么状态 + 去哪里」，不再是 5 张「暂无 X」的全宽空卡。
  4. 侧栏从目录变成工具：属性表全程粘住，加页面锚点、资料完整度环、来自合成链的相关条目，替代原来只写「可查看／暂无」的资料概览。
  5. 动效（静态图看不到）：稀有度光环 5.4s 呼吸、节点 hover 上浮 1px、层间连接线渐显、锚点切换高亮位移，均在 180–280ms 区间。
  6. 色值、圆角、间距、字号全部取自 hifi-preview.css / tokens.css 既有令牌，稀有度色是唯一新增语义色（浅红 #ff8f8f，仅用于光环与稀有度文本）。
