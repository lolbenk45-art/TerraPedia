设计注记 · NPC 详情页 v1

  1. 消除重复陈列：线上页面底部的「出售相关」6 行与上方「出售物品」是同一批数据的两种画法，本稿删掉后者，商店只有一处。
  2. 商店按解锁条件分组：34 项拆成 常驻 13 / 进度 8 / 环境 5 / 持有 3 / 节日 5，条件从 notes 字段升为分组依据——玩家的真实问题是「现在能买什么」，不是「一共有什么」。分组计数直接做成筛选段控件。
  3. 入住条件从段落变清单：原 behaviorNotes 是一整段掺着分号的文字，拆成两条可核对项，「便携收纳内的钱不计入」这个坑作为附注挂在条件下。
  4. 幸福度给结论而不是罗列：左侧直接给「森林 + 公主/高尔夫球手/护士」的推荐方案和它换来的折扣与晶塔，右侧才是喜欢/不喜欢/讨厌三列明细。原页面三列等宽平铺，右两列大量留白。
  5. 空模块压成事实条：掉落物、状态效果对友好 NPC 本就不适用，写「不适用」比两张「暂无」空卡诚实。
  6. 数据问题（本稿如实呈现，未美化）：5 项节日商品的 imageUrl 指向完全无关的物品——情人节戒指→永恒旅者兜帽、心箭→浪人浴衣、Wiesnbräu啤酒→脊椎龙头、火鸡羽毛→细条纹裤、节日大礼帽→蚁狮卵。这是 Wiki 抓取错位，需要在数据侧修，不是前端能兜的。已在商店页脚和事实条里标出。
  7. 高度阶梯（第二轮质感修复）：初版三层嵌套用同一套「1px 暖金 hairline + 2% 表面」，明度差不足读成一层。现改为 L0 页面底（压深并加暗角）→ L1 卡片浮起（顶部高光 + 可见投影）→ L2 分组带下沉（内阴影凹槽）→ L3 条目再浮起（高光 + 落影），物品图标另做凹槽。主线模块（合成链 / 商店）加金点与金色渐隐标题栏，次级模块降一档亮度。
  8. 色值、圆角、间距、字号取自 hifi-preview.css / tokens.css；好感度三色复用既有暖色带（苔绿/暖金/砖红），未引入新品牌色。
  9. 价格用具体币种：数值后带「铂金币 / 金币 / 银币 / 铜币」，词表取自 front-nuxt/utils/price.ts，复合价格如「2 银币 50 铜币」按段拆分。
