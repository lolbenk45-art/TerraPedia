# Current Project Plans

本目录保存仍在推进的项目级计划和里程碑。这里面向跨任务、跨阶段的项目级工作，不保存单个 worker 的任务级执行计划。

历史计划已归入 `docs/project-governance/archive/` 和 `docs/project-governance/legacy/`。`legacy/**` 是历史 cluster，禁止新增文件。

新增项目级计划应直接放入本目录。任务级可执行计划应放 `docs/plans/` 或 `docs/superpowers/plans/`，临时过程上下文应放 `task/`。
