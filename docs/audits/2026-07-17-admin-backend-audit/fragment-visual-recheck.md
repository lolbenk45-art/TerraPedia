# 视觉复核（CJK 字体修复后）

全局备注：
1. 顶部橙色告警条（"请注意 预览配方关系差异·执行失败"）悬浮在每页面包屑区中央，与页头抢占视觉焦点且始终常驻，属全局层次干扰。
2. 中英混排：中文落到微软雅黑、拉丁/数字仍是 Plus Jakarta Sans，整体可接受——数字（KPI 大数、时间戳）的几何圆润感与雅黑中性笔形没有明显冲突；但同字号下拉丁 x-height 偏小、字重偏轻，混排行（如"维护 Any 类型来源组"、"Armor Set 管理"）里英文略显"陷下去"，粗体处雅黑疑似伪粗与 Jakarta 真粗对比后发虚。建议给 CJK 显式声明 fallback 字重或换用思源黑体系。
3. 多页表格"操作"列与状态 pill 存在逐字竖排折行（"详/情"、"已启/用"），是列宽预算问题而非字体问题。
